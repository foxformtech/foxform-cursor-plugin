# Changelog

## 1.0.0

First release.

- Remote MCP server at `https://mcp.foxform.app/mcp` over Streamable HTTP.
- Ten tools: list, get, create, update, publish and unpublish forms; list, get and export
  responses; per-screen analytics.
- Authentication with a FoxForm API key supplied as the `FOXFORM_API_KEY` variable and
  sent as the `x-api-key` header.
- `create-quiz-funnel` skill covering scored choices, `calc()` expressions, conditional
  navigation and result cards.
